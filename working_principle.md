Working Principle

1. The NodeMCU ESP8266 is powered using a suitable power supply.
2. The microcontroller attempts to connect to the configured Wi-Fi network.
3. The device communicates with the Blynk IoT platform.
4. The user operates the configured controls in the Blynk application.
5. The microcontroller processes the commands according to the uploaded program.
6. The connected output devices respond to the commands.
7. The system is tested to verify connectivity and correct operation.

Testing

Document the Wi-Fi connection status, Blynk device status, output response, and any issues observed during testing.
